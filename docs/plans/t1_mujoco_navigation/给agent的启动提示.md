# 把单步交给 agent 的提示

先按单步文件名选择对应配置，再把下列提示中的 W01 和文件路径替换成目标步骤。任务文件、共享规则和记录需要一起可访问；不必把整个聊天历史复制过去。

```text
请执行这份任务包中的 W01，只做这一步。
首先读取本任务包的 总规划.md、执行规则.md、环境定位.md、执行看板.md、交接记录.md，
再读取 W01 对应单步规划和 records/W01.md。

真实开发目录与规划目录在 环境定位.md 中。工作目录必须是 /home/haoyang/humanoid_nav_ws。
核查前置依赖和项目仓库的 Git 状态后，从已有断点继续。
每完成一个检查点，就更新记录中的已完成、正在做、未完成、命令、结果和证据。
不要只在聊天中记录。不要重做已验收工作，不自动进入下一步。
全程使用 Git version control：开始时记录分支和HEAD；实现与测试通过后先提交实现，再更新并提交看板、交接和执行记录。
如遇上下文或额度限制，优先保存 checkpoint 与交接，写明下一条命令、cwd、进程和失败原因。
结束时报告状态、验收、实现提交SHA、交接记录提交SHA、剩余限制。完成本步后停止，等待用户分派下一步。
```

若之前会话中断，增加一句：“这是同一步的续接；以交接记录、records/Wxx.md和实际Git状态为准，先核对上次未提交差异。”
如果agent不能访问WSL或本规划目录，让它报告具体权限/路径失败，不允许在Windows新建替代代码工程。
