# W11 自主导航与静态避障

难度：L5 高难。估算投入：4–8小时，含调试与验证，不是保证。
依赖：W10。覆盖需求：R1、R2、R3、R4、R5。遵循决策：D3、D4、D6、D7。

## 目标和产物

在保存地图中自主完成静态A到B导航。产物：
- Nav2全局规划器、MPPI、行为树、costmap和goal/progress checker配置。
- navigation.launch.py整链路与程序化目标发送入口。
- 静态导航测试证据与冻结参数。

## C1：连接导航系统

复用W09地图/AMCL和W10安全链；按生命周期依赖启动，等clock、TF、scan、定位就绪再激活导航。
全局规划器先用NavFn或SmacPlanner2D的一个，说明选择即可；不要同时维护两套。
MPPI初始使用DiffDrive，vy=0。DiffDrive只是平面速度约束近似，T1的动力学仍由步态策略负责。
将W05实际前进/转向/制动能力写入速度、加速度和预测模型。不能把策略输入单位直接填作真实m/s。
设置保守footprint与膨胀，local costmap接/scan，合理raytrace清除。避免起点位于自身障碍或膨胀区。

## C2：解决双足导航特有行为

验证接近目标时的小速度请求和策略死区。合理停止距离与goal tolerance必须预先冻结，不能测试失败后随意放宽。
进度检查器容许步态启动和安全等待，但不能无限等待。单次任务有时间上限和明确FAILED状态。
禁止未验证的spin/backup默认恢复；每个启用恢复行为都要经过W05/W10支持，尤其转向身体扫掠。
代价地图以合适高度的扫描为观测，障碍高度和range参数与W08一致；虚拟平面扫描不能被误解为3D占据。
录制导航输出、安全过滤输出、策略输入、实际速度四者，诊断轨迹偏差发生在哪一层。
如果MPPI因性能或动力学近似持续失败，先做最小诊断；需要切换单个控制器时写ADR和重新验证，不同时开发多个规划系统。

## C3：分级闭环实验

先短直线，再转角，再绕静态障碍，最后完整A→B。
目标由RViz或NavigateToPose action下发；不能脚本按真值硬编码一串速度充当自主导航。
预定义5个起点/目标组合，至少一个必须绕过静态障碍。每次从复位后开始，有固定场景、地图与参数SHA。
测试目标取消与更换，检查旧目标命令不会在取消后继续执行。
机器人必须通过真实接触行走，测试程序不能调用set base pose推进路程。

## C4：验收

- 五次预定义任务全部到达，符合冻结的位置/yaw/稳定时间判据，无环境碰撞和跌倒。
- 至少一次存在明显绕障路径；Nav2 action成功与实际终点误差均记录。
- 停止/取消符合W10包络；失败有原因、不会死循环。
- 没有非法TF、空scan或丢失定位被忽略的持续错误。
- 保存至少一段可视证据和机器可读trajectory/results，记录完整参数版本。

## 边界与失败处理

静态到点未通过不能添加复杂动态场景。若机器人因死区完全不能逼近目标，应修复速度契约或明确可达目标容差，不伪造成功action，不瞬移到终点。
