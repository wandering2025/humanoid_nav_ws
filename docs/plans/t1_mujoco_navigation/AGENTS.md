# T1 MuJoCo 导航规划目录的 agent 指令

本目录位于 Booster T1 导航项目 Git 仓库内部，保存规划与执行记录。真实代码根目录由环境定位.md 中的 `$WS` 指定。
开始执行时按顺序读取：总规划.md、执行规则.md、环境定位.md、执行看板.md、交接记录.md、用户指定步骤、records/Wxx.md。
一次只执行一个步骤，使用该步骤文件名指定的配置，不自动进入下一步或委派。
在同一个项目仓库中维护 TODO / IN_PROGRESS / DONE / BLOCKED / PAUSED / FAILED 状态和 Git 提交；不能把未运行的测试标为通过。
每个完成检查点及上下文即将耗尽前更新交接，记录代码 SHA、脏文件、已做/在做/未做、证据和下一条命令。
不得重装基础环境、修改干净上游仓库或移动代码工作区来绕过集成问题。所有修改服从执行规则.md。
