# W16 未知场景探索导航

2026-10-19（Europe/Berlin）。用户明确分派 W16 实现与验证；串行，无委派。

目标：机器人仅获知起点 A 坐标系下的 B=(dx,dy)，从空白 SLAM 会话出发，依据在线观测选择探索目标，找到已观测安全路线后到达 B。A 的 +x 为初始朝向，+y 为左侧；不要求指定终点朝向。

范围：独立探索入口、纯地图 frontier 决策、独立无 truth 订阅的 ROS 决策进程、在线 Nav2、可审计决策记录。保留既有 guided demo 与用户 goal.yaml 修改。初版静态验收作为历史保留；用户本轮要求同时完成下述D1–D3真实动态验证。物理策略、传感器、安全链与冻结上游不改。

信息契约：任务仅含 B 坐标；不得读场景几何、预制地图、观测航点、覆盖矩形或固定终点进近。模拟器独立读取世界；评测可读 truth，但不能向探索进程提供反馈。map→odom 始终由 SLAM 独占。当前理想 odom 下以启动时 odom 位姿定义 A，按实时 map→odom 换算 B；不宣称漂移里程计的全局锚定。

检查点：
- C1：记录起始状态、实现接口与算法、离线测试（遮挡/死路/回退/不可达/坐标变换/输入隔离），系统 colcon 构建。
- C2：headless 真实物理 A→B，未知区域不当自由空间；安全停车、无接触/跌倒、单一 TF 与命令 ownership；保存每次决策的实际地图与打分。
- C3：改变墙与通道布局后，同一任务/算法自动改变路线；不可达目标有界失败并停车。实验失败完整保留，不以反复筛选声称可靠性。
- C4：交付一条运行命令、说明与证据；实现/证据先提交，完成/交接后提交。无 GUI/录像要求。

到达标准：B 位置误差≤0.30m，物理站稳≥2s，速度<0.05m/s、角速度<0.05rad/s；原位置门槛与安全停车标准保留，因输入未指定姿态不设固定 yaw。超时或 frontier 耗尽只能报告未找到路线，不能推断任意未知世界中 B 绝对不可达。

参考：[frontier 原论文](https://www.cs.cmu.edu/~motionplanning/papers/sbp_papers/integrated1/yamauchi_frontiers.pdf)、[Nav2 Jazzy 在线 SLAM 接口](https://docs.nav2.org/jazzy/tutorials/general_tutorials/navigation2_with_slam/navigation2_with_slam/)。本步使用已有环境，不安装新依赖。

## 用户追加的动态障碍验收（本轮必须完成）

D1：在同一未知探索任务中启用真实 MuJoCo mocap 碰撞体，由 physics owner 按仿真时间移动；原始 /scan 进入 Nav2 和 Collision Monitor。探索器及建图过滤器不得读取场景、障碍真值/时序、旧航点。SLAM持续处理观测，不按评测真值暂停。
D2：实际位移≥1m，事件完成；活动期雷达命中≥3帧、local costmap 标记≥2帧；远离B的真实站稳等待≥2s且最终命令为0，事件结束后恢复运动≥1m，最终B≤0.30m且站稳≥2s。零环境/障碍/非足接触、零跌倒、原TF/命令隔离与清理检查必须全通过。依据在线scan变化抑制动态回波进入静态SLAM；记录过滤审计并核验清空后的通行。
D3：相同任务/算法的无动态实体对照到达；CPU测试和构建、地图路径逐快照复验、所有失败保留，更新运行说明及交接。默认入口启用动态事件；显式 `--static` 用于历史布局和无障碍对照，不将静态成功冒充动态成功。无图形验证范围保留。

## 用户追加图形入口（本轮G1–G3）

用户要求与旧演示相同的一行GUI启动，覆盖上述历史“无图形”范围。默认同时启动MuJoCo与RViz，保留显式--headless、--no-rviz、--hold；真实动态EXP01仍默认启用。A/B显示使用探索器锁存的实际A系解析值；RViz只展示真实SLAM、scan、当前规划与实际轨迹，不预置路线。沿用现有GPU监控、退出/进程/端口契约。
G1完成实现/CPU/四包构建；G2实际运行GUI完整动态探索、保存截图及安全/动态/GPU/清理证据；G3交付一行命令给用户测试。用户明确要求收到其测试反馈之后才往presentation/加入新命令，本轮该目录全部保留。

G2故障修复补充：无可达frontier时先停车观察；20s后允许在已知可达域内选择1.5–4m的新观察位置并用真实Nav2验证执行，解决静止有限射线残留costmap占据。没有安全候选仍最多等待60s；总预算与安全阈值不变。等待轮询不占实际导航决策次数。不得以清空地图或真值触发替代重新观测。
