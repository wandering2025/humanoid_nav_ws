# 优化版本讲解提纲

当前图形恢复及新录像未验收；不要用旧版录像冒充以下流程。先看[当前验收记录](optimization-review.md)。

1. **A与空白地图**：这是Booster T1的物理步行仿真，LiDAR正在构建地图；使用理想里程计及真值姿态补偿。
2. **连续观测路线**：机器人自主执行guided autonomous mapping。经过宽敞西区、北廊与遮挡后的东区；没有遥控，不宣称frontier exploration。
3. **所得地图上的规划**：地图足以支持A-B规划后，青线显示NavFn计算的完整路线概览；蓝线是当前位置正在执行的路线，由高级专用RPP跟踪；全局规划仍为NavFn。机器人从这里继续去B，不返回A重走。紫线显示实际走过的路线。
4. **地图与动态层分离**：临时障碍不应写入建筑静态图。动态导航阶段暂停SLAM修正，定位依赖理想里程计；LiDAR与costmap/安全链继续工作。验证到B后恢复SLAM。
5. **明显干扰**：橙色移动障碍横向进入路径、停留8秒。指出机器人真实停止、等待/重规划状态与路径年龄；撤离后重新规划并继续。保护区停车是否触发取决于进入时机，不能把规划等待都称作Collision Monitor停车。
6. **B与安全结果**：最后沿直线接近B，验证位置、朝向及静止，再锁存停车。终端Final SUCCESS还要求接触/跌倒0、正常进程退出及端口释放。

说明比较图：移除了原版返回A的往返和逐个航点停稳；路线长度/流程时长改善来自任务组织变化，不是同条件规划算法性能基准。主动说明新的B位置、动态障碍尺寸、静态图冻结和现有传感器假设。
