# Advanced SLAM and Navigation Demo v0.2 讲解

先说明任务：T1 需要走到隔墙另一侧的 B，起初没有完整地图。场景的挑战来自遮挡、多个区域和转弯；北侧通道宽 7.5 米，安全距离没有缩小。

1. **A / 初始地图**：指出青色 A、绿色 B 和中间隔墙。RViz 起初只显示少量已知区域。说明使用模拟 LiDAR，9×360 射线、10 Hz，加入 1 cm 距离噪声。
2. **自主建图**：机器人自动执行 9 个预定义航点，观众观察地图随着移动逐渐形成。Nav2 只在已知空间规划；新航点在前方区域被扫描后执行。这是 guided autonomous mapping，不是 frontier exploration，也不需要键盘遥控。
3. **结构和回到 A**：西区→北廊→东区→北廊→A。SLAM Toolbox 持续维护地图，实际 OccupancyGrid 通过 map_saver 保存；没有把场景几何预先栅格化给规划器。
4. **利用所得地图导航**：展示从 A 绕隔墙北端再转入东区、到 B 的蓝色非直线路径。没有切换 AMCL，SLAM 始终是唯一 map→odom 发布者。
5. **动态障碍**：橙色箱体靠近路线、停留再退出。指出 LiDAR 点与局部代价变化、规划路径偏移及机器人实际绕行。最终验证运行若未触发停车，不称其为“安全等待”。机器人没有得到障碍未来轨迹或评测真值。
6. **B / 结果**：绿色 B、到达验证、安全停稳、零碰撞/零动态接触/零非足接地/零跌倒。退出后再确认进程清理和端口释放，屏幕上的后处理证据卡会明确标注。

技术选择：复用稳定的 T1 policy/PD 步行、ROS 2 Jazzy、MuJoCo、Nav2、SLAM Toolbox 和 RViz。采用固定建图路线是为了在已知宽敞场景中可重复展示地图增长、真实步行和动态导航；没有为探索算法引入不必要的现场风险。

必须主动披露：理想真值里程计与真值姿态 LiDAR 补偿；平地、固定场景、固定种子与预设建图航点；运动障碍是不可推动的 mocap 碰撞体；响应式避障没有未来预测；这是仿真演示，不是硬件验证或可靠性认证。历史 W13 仍为 FAILED/36/40，不被本次成功覆盖。

录像左右分别为 MuJoCo 与 RViz，同一次运行、保留实际经过时间，4 fps、无音频；末尾 8 秒为明确标记的运行后证据卡。逐帧窗口抓取与编码分离，录像不会控制机器人。
