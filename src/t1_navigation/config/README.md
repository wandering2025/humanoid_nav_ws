# Navigation configuration

| File | Purpose |
| --- | --- |
| `exploration_task.yaml` | Relative destination in the starting body frame |
| `slam.yaml` | SLAM Toolbox mapping and map-frame ownership |
| `advanced_controller.yaml` | NavFn, Rotation Shim, and Regulated Pure Pursuit for exploration and guided navigation |
| `safety.yaml` | Command gate, velocity smoother, and Collision Monitor |
| `navigation.yaml` | Saved-map navigation configuration |
| `localization.yaml` | AMCL and map-server configuration |
| `*.rviz` | Visualization layouts |
